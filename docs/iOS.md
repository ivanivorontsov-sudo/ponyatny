# Сборка программ на «Понятном» для iPhone и iPad

Начиная с версии 2.7 команда

```
ponyatny собрать программа.pon --ios [-o папка] [--название "Моя игра"] [--id ru.imya.igra]
```

создаёт готовый проект Xcode (через XcodeGen): нативная оболочка на Swift с `WKWebView`, в которую встроены скомпилированная программа, ядро «Понятного» и графика (`окно`, `каждый_кадр`, кнопки, клавиши, касания). Ввод `спроси()` показывается системным окном iOS; «Отмена» спокойно завершает программу.

Сам `.ipa` собирается только на macOS (так устроены инструменты Apple): на своём Mac — скриптом `папка/sobrat-ios.sh`, без Mac — в GitHub Actions (workflow «Сборка под iOS», запуск вручную из вкладки Actions).

## Без подписи

Если переменные подписи не заданы, `sobrat-ios.sh` собирает неподписанную сборку для симулятора (`build/<Имя>-simulator.zip`). Это проверка, что проект компилируется. Поставить её на настоящий iPhone нельзя.

## С подписью: что нужно от владельца аккаунта Apple

Подпись делается только через переменные окружения или секреты GitHub. В репозитории, в коде и в собранных файлах ключей нет.

1. Платный аккаунт **Apple Developer Program** (99 $ в год). Из него нужен **Team ID**: 10 символов, раздел Membership.
2. **App ID** (Identifiers) с идентификатором, например `ru.vorontsov.igra`.
3. **Сертификат** «Apple Distribution» (для ad-hoc и App Store) или «Apple Development», выгруженный из «Связки ключей» в `.p12` с паролем.
4. **Профиль** (Provisioning Profile) для этого App ID и сертификата: ad-hoc (с UDID ваших устройств), development или App Store.
5. Секреты в репозитории GitHub (Settings → Secrets and variables → Actions):

| Секрет | Что положить |
|---|---|
| `IOS_TEAM_ID` | Team ID |
| `IOS_CERT_P12_BASE64` | `base64 -i cert.p12` |
| `IOS_CERT_PASSWORD` | пароль от `.p12` |
| `IOS_PROFILE_BASE64` | `base64 -i profile.mobileprovision` |

При запуске workflow укажите программу, название и идентификатор (тот же, что в профиле) и способ подписи (`ad-hoc`, `development` или `app-store`). Сертификат импортируется во временную связку ключей, которая удаляется в конце сборки. Результат — `.ipa` в артефакте `ios-app`. Ad-hoc-сборку можно поставить на устройства из профиля (например, через Apple Configurator или Finder), App Store-сборку — загрузить через Transporter.

На Mac то же самое: задайте эти переменные в терминале и запустите `./sobrat-ios.sh`; нужен Xcode 15 или новее (XcodeGen скрипт поставит через Homebrew).
