# Язык «Понятный» — полное описание синтаксиса (версия 2.1)

«Понятный» — язык программирования с русскими словами. Программа — это текстовый файл `.pon` в кодировке UTF-8.
Компилятор переводит её в JavaScript, а из него может собрать отдельную программу `.exe` (Windows) или исполняемый файл (Linux).

## 1. Общие правила

- Одна команда — одна строка. Отступы не обязательны, но помогают читать код.
- Блоки (`если`, `пока`, `функция`, `класс` …) всегда заканчиваются словом `конец`.
- Комментарий — от `#` или `//` до конца строки.
- Служебные слова пишутся маленькими буквами или с большой первой буквы (`Если`, `если`).
- Язык умный и прощает мелкие опечатки в служебных словах (см. раздел 14а).
- Имена: буквы (любая кириллица — русская, украинская, белорусская … — и латиница), цифры, `_`; начинаются не с цифры. Длина имени — до 255 символов. `счёт` и `счет`, `Имя` и `имя` — разные имена.
- В одной части имени нельзя смешивать русские и латинские буквы: `сoк` с латинской `o` выглядит как `сок`, но это другое имя, поэтому компилятор такое запрещает и подсказывает правильное написание. Части, разделённые `_`, могут быть на разных алфавитах: `get_Имя` можно.
- Текст программы приводится к форме Юникода NFC, поэтому `й`, набранная как `и` + знак краткой, — та же буква `й`. «Совместимые» формы букв (например, лигатура `ﬁ`) в именах запрещены.
- Невидимые символы направления текста (U+202A–U+202E, U+2066–U+2069, U+200E, U+200F, U+061C) и невидимые символы нулевой ширины (U+200B–U+200D, U+2060, U+00AD) запрещены во всём тексте, включая строки и комментарии: через них код может выглядеть не так, как работает (атака Trojan Source, CVE-2021-42574). Если такой символ нужен в строке, пишите `\u{202E}`.
- Внутренние имена JavaScript (`constructor`, `prototype`, `__proto__`, `toString`, `call`, `apply`, `bind` и любые имена, начинающиеся с `__`) нельзя писать после точки и нельзя давать полям и функциям классов. Ключи словаря могут быть любыми строками.
- Внутри скобок `( )`, `[ ]`, `{ }` можно переносить строку.
- Нумерация элементов списков и строк начинается с 0; отрицательный номер считается с конца (`с[-1]` — последний).

### Служебные слова

`пусть константа навсегда напиши если то иначе пока повторить раз для каждого из от до шаг функция верни конец и или не в истина ложь ничего стоп дальше попробуй ошибка как наконец брось выбор вариант когда класс наследует структура это себя родитель новый подключи затем`

Слова `каждого из от до шаг раз ошибка как наконец наследует` — особые только на своём месте, в других местах их можно использовать как имена.

## 2. Типы

| Тип | Примеры | `тип(x)` |
|---|---|---|
| число | `5`, `3.14`, `1_000_000` | `"число"` |
| строка | `"текст"`, `«ёлки»`, `"Привет, {имя}!"` | `"строка"` |
| логическое | `истина`, `ложь` | `"логическое"` |
| список | `[1, 2, 3]`, `[]` | `"список"` |
| словарь | `{"ключ": 1, имя: "Оля"}`, `{}` | `"словарь"` |
| функция | `функция(x) => x * 2` | `"функция"` |
| ничего | `ничего` | `"ничего"` |
| объект класса | `Кот("Барсик")` | имя класса |

Дробные числа печатаются с запятой: `напиши 7 / 2` → `3,5`.
Ложными считаются `ложь`, `ничего`, `0` и пустая строка `""`; всё остальное — истина.

Тип можно указать (необязательно), тогда он проверяется:
```
пусть возраст: число = 12
функция площадь(a: число, b: число) -> число
    верни a * b
конец
```
Типы для указания: `число строка логическое список словарь функция ничего любое` и имена классов.

## 3. Переменные и константы

```
пусть x = 5            # обычная переменная, её можно менять
x = x + 1
x += 2                 # также -=  *=  /=  %=
константа МАКС = 100   # имя нельзя переназначить
пусть навсегда дни = ["пн", "вт"]   # нельзя ни переназначить, ни менять внутри
```
- `константа` запрещает `МАКС = …` (ошибка при компиляции).
- `пусть навсегда` запрещает и переназначение (при компиляции), и изменение содержимого (при выполнении): `дни.добавь("ср")` → «это значение объявлено «навсегда», его нельзя менять».
- Переменную нужно объявить через `пусть` до первого присваивания. Внутри блока можно объявить своё имя, оно видно только в этом блоке.

## 4. Выражения и приоритет операций (от слабого к сильному)

| Уровень | Операции |
|---|---|
| 1 | конвейер `затем`, `\|>` |
| 2 | `или` |
| 3 | `и` |
| 4 | `не` |
| 5 | `== != < > <= >=`, `в`, `не в` |
| 6 | `+ -` |
| 7 | `* / %` |
| 8 | унарный `-` |
| 9 | `^` (степень, правоассоциативная) |
| 10 | вызов `f(x)`, индекс `a[i]`, поле `a.b`, безопасные `?.` и `?.[ ]` |

- `+` складывает числа, склеивает строки (если хотя бы одна сторона строка) и списки.
- `строка * число` повторяет строку.
- `%` — остаток, всегда неотрицательный для положительного делителя.
- `x в коллекция` — есть ли элемент в списке, подстрока в строке, ключ в словаре.
- `если условие то а иначе б` — условное выражение.
- Также понимаются символы `≠ ≤ ≥ × ÷`.

### Шаблоны строк
Внутри любой строки `{выражение}` заменяется значением: `"Привет, {имя}! Через год тебе {возраст + 1}."`
Чтобы написать саму фигурную скобку — `\{` и `\}`. Ещё экранирование: `\n` (перевод строки), `\t`, `\r`, `\"`, `\\`, `\«`, `\»` и `\u{КОД}` — любой символ Юникода по шестнадцатеричному коду (`\u{263A}` → ☺).

### Конвейер
`x затем f` — то же, что `f(x)`; `x затем f(a)` — то же, что `f(x, a)`.
Если `f` — не функция, а функция значения (метод), вызывается `x.f()`:
```
напиши текст затем обрезать затем маленькими
напиши [3, 1, 2] |> отсортировано |> соедини("-")
```

### Безопасный доступ `?.`
`покупатель?.заказ` даёт `ничего`, если `покупатель` — `ничего` (или нет такого поля); дальше цепочка тоже безопасна: `к?.заказ?.номер`.
`покупатель?.заказ = 5` записывает, только если `покупатель` — не `ничего`.
`список?.[0]`, `объект?.метод()` работают так же.

## 5. Ввод и вывод

```
напиши "Сумма:", a + b      # значения через пробел
пусть имя = спроси("Как тебя зовут?")
пусть n = число(спроси("Сколько?"))
```

## 6. Условия

```
если x > 10 то
    напиши "много"
иначе если x > 5 то
    напиши "средне"
иначе
    напиши "мало"
конец
```
Слово `то` можно не писать в конце строки.

## 7. Циклы

```
пока условие
    …
конец

повторить 3 раз
    …
конец

для каждого элемент из список      # список, строка (по буквам) или словарь (по ключам)
    …
конец

для каждого ключ, значение из словарь   # для списка: номер, элемент
    …
конец

для i от 1 до 10            # включительно; если начало больше конца — идёт вниз
    …
конец

для i от 0 до 100 шаг 5      # шаг может быть отрицательным, но не нулём
    …
конец
```
`стоп` — выйти из цикла, `дальше` — перейти к следующему кругу. Вне цикла это ошибка компиляции.

## 8. Выбор

```
выбор n
    вариант 0
        напиши "ноль"
    вариант 1, 2, 3                  # несколько значений
        напиши "мало"
    вариант 7 если премия то         # вариант с дополнительным условием
        напиши "счастливое"
    когда x если x > 100 то          # x — это n, и условие на него
        напиши "очень много"
    иначе
        напиши "что-то другое"
конец
```
Выполняется первый подходящий вариант, «проваливания» в следующий нет.

## 9. Функции

```
функция привет(имя, знак = "!")          # значение по умолчанию
    верни "Привет, " + имя + знак
конец

функция факториал(н)                      # рекурсия
    если н <= 1 то
        верни 1
    конец
    верни н * факториал(н - 1)
конец
```
- Функции, объявленные в блоке, видны во всём блоке (можно вызывать до объявления).
- Количество значений при вызове проверяется при компиляции.
- Без `верни` функция возвращает `ничего`.

### Безымянные функции (лямбды)
```
пусть удвоить = функция(x) => x * 2
пусть квадрат = x => x * x
пусть сложная = функция(a, b = 1)
    верни a * b
конец
напиши [1, 2, 3].преобразуй(x => x * 10)
```
Лямбды запоминают переменные вокруг себя (замыкания).

## 10. Классы и структуры

```
класс Животное
    пусть имя = "безымянное"           # поле со значением по умолчанию
    функция создать(имя)               # вызывается при создании
        это.имя = имя                  # «это» и «себя» — текущий объект
    конец
    функция голос()
        верни "..."
    конец
    функция строкой()                  # как печатать объект
        верни "{это.имя} говорит {себя.голос()}"
    конец
конец

класс Кот наследует Животное
    функция голос()
        верни "мяу, а не " + родитель.голос()
    конец
конец

пусть к = Кот("Барсик")        # или: новый Кот("Барсик")
напиши к

структура Точка(x, y = 0)       # короткий класс только с полями
пусть т = Точка(3, 4)
т.y = 5
```

## 11. Ошибки

```
попробуй
    напиши 1 / 0
если ошибка как е             # е — текст ошибки (или значение из «брось»)
    напиши "Ошибка:", е
наконец                       # необязательно, выполняется всегда
    напиши "готово"
конец

брось "что-то пошло не так"   # своя ошибка
```

## 12. Модули

```
подключи "математика.pon"
```
Пишется на верхнем уровне программы. Путь — относительно текущего файла, `.pon` можно не писать. Каждый файл подключается один раз. Всё, что объявлено в подключённом файле, становится доступно.

### Функции строк (`текст.функция(…)`)
`длина` (поле), `большими()`/`заглавными()`, `маленькими()`/`строчными()`, `обрезать()`, `содержит(подстрока)`, `заменить(что, чем)`, `разделить(разделитель)`, `начинается(с)`, `заканчивается(на)`, `найди(подстрока)`, `срез(от, до)`, `повтори(n)`, `символы()`, `с_заглавной()`, `перевёрнуто()`, `число()`.

### Функции списков
`длина`, `добавь(x)`, `вставь(номер, x)`, `убери(номер)`, `содержит(x)`, `найди(x)`, `соедини(разделитель)`, `сортируй()`, `отсортировано()`, `обрати()`, `срез(от, до)`, `отфильтруй(условие)`, `преобразуй(функция)`, `свернуть(функция, начало)`, `для_каждого(функция)`, `сумма()`, `первый()`, `последний()`, `копия()`, `пусто()`, `очисти()`.

### Функции словарей
`длина`, `ключи()`, `значения()`, `пары()`, `есть(ключ)`, `получи(ключ, по_умолчанию)`, `убери(ключ)`, `копия()`, `пусто()`, `очисти()`. Значение можно взять как `д["ключ"]` или `д.ключ`.

## 13а. Стандартная библиотека (`подключи "стд/…"`)

Встроена в компилятор, файлы скачивать не нужно. Подключайте только нужный модуль:

```
подключи "стд/консоль"
пусть возраст = спроси_число("Сколько вам лет?", 1, 120)
рамка("Привет! Вам " + текст(возраст))
```

| Модуль | Что внутри |
|---|---|
| `стд/математика` | `факториал(н)`, `нод(а, б)`, `нок(а, б)`, `простое(н)`, `среднее(список)`, `медиана(список)`, `процент(часть, целое)`, `ограничь(x, от, до)`, `в_радианы(г)`, `в_градусы(р)`, `чётное(н)` |
| `стд/строки` | `дополни_слева(т, ширина, символ?)`, `дополни_справа(…)`, `по_центру(т, ширина)`, `слова(т)`, `сколько_раз(т, кусок)`, `это_число(т)`, `палиндром(т)`, `с_большой(т)` |
| `стд/списки` | `уникальные(с)`, `подсчитай(с)` → словарь, `разбей(с, размер)`, `соедини_пары(а, б)`, `наибольший_по(с, ф)`, `сгруппируй(с, ф)` → словарь, `диапазон(от, до, шаг?)` |
| `стд/случай` | `случайный_элемент(с)`, `перемешай(с)`, `кубик(граней?)`, `монетка()`, `пароль(длина?)`, `с_вероятностью(п)` |
| `стд/время` | `сегодня()` → «ДД.ММ.ГГГГ», `сейчас()` → «ЧЧ:ММ», `день_недели()` → «понедельник»…, `дата_словами()`, `високосный(год)`, `дней_в_месяце(м, год)`, `подожди(секунд)`, класс `Секундомер` (`.прошло()`, `.сброс()`) |
| `стд/консоль` | `спроси_число(вопрос, от?, до?)` — переспрашивает, пока не введут число; `спроси_да_нет(вопрос)`; `меню(заголовок, пункты)` → номер (0 — выход); `рамка(т)`; `полоска(доля, ширина?)`; `таблица(заголовки, строки)`; `очисти_экран()`; `деньги(сумма)` → «1 234,50 ₽» |
| `стд/файлы` | `прочитай_строки(путь)` (нет файла → `[]`), `запиши_строки(путь, с)`, `допиши_строку(путь, т)`, `сохрани_словарь(путь, сл)`, `загрузи_словарь(путь)` |

Имена из библиотеки нельзя объявлять заново в своей программе: будет ошибка о повторном имени. Неизвестный модуль даёт ошибку «файл „стд/…“ не найден».

## 14. Сообщения об ошибках

Ошибки пишутся по-русски с номером строки и столбца, при опечатках — с подсказкой:
```
Строка 2, столбец 1: непонятная команда «коннец». Возможно, вы имели в виду «конец»?
Строка 5, столбец 8: не знаю, что такое «счет». Возможно, вы имели в виду «счёт»?
Строка 1, столбец 7: в имени «сoк» смешаны русские и латинские буквы («сoк»). … Возможно, вы имели в виду «сок»?
Строка 1, столбец 14: сравнения нельзя писать цепочкой: «a < b < c» понимается неоднозначно. Напиши через «и»: a < b и b < c
Строка 3, столбец 1: нельзя изменить «дни»: она объявлена как «пусть навсегда»
Строка 7: в списке нет элемента с номером 5 (элементов: 3, нумерация с 0)
```
При компиляции проверяются: необъявленные имена, повторные объявления, изменение констант, `стоп`/`дальше` вне цикла, `верни` вне функции, `это` вне класса, количество значений при вызове функций, неизвестные типы и явное несовпадение типа.

## 14а. Опечатки, которые язык прощает

Компилятор сам исправляет опечатку в служебном слове и пишет предупреждение, но только там, где это не может изменить смысл правильной программы:

1. **Слово в начале команды**, за которым сразу идёт имя, число или строка (а не `=`, `(`, `.` и т. п.): `пуст x = 1`, `напишы x`, `ЕСЛИ x > 1 то`. Правильная программа так начинаться не может, поэтому двусмысленности нет. Если переменная называется `пуст` и стоит `пуст = 2`, это присваивание, и ничего не исправляется.
2. **Слово-окончание блока** одно на строке: `конц`, `инче` → `конец`, `иначе`.
3. **Ожидаемое слово** на своём месте: `повторить 3 рза` → `раз`, `для i от 1 дo 5` → `до`, `тo` → `то`.
4. **Латинские буквы-двойники** в служебном слове: `пoка` с латинской `o` → `пока`.

Исправление делается, только если опечатка — одна правка (лишняя, пропущенная, заменённая буква или две переставленные соседние) и подходящее слово ровно одно. Слова короче 3 букв не исправляются. Если вариантов несколько или опечатка больше, компиляция останавливается с подсказкой «Возможно, вы имели в виду …». Опечатки в именах переменных и функций **никогда** не исправляются автоматически — только подсказываются, потому что это могли быть разные имена.

Предупреждения выглядят так:
```
Предупреждение. Файл «prog.pon», строка 1, столбец 1: опечатка «пуст» исправлена на «пусть»
```

## 14б. Ограничения (защита от зависаний)

- Вложенность выражений и блоков — не больше 200 уровней.
- Строка — не длиннее 100 миллионов символов (`"a" * 10^12` даёт понятную ошибку, а не падение).
- В песочнице и в `запустить` из тестов программа останавливается после 5 миллионов шагов цикла, в песочнице ещё и через 20 секунд. В собранных программах ограничения шагов нет.
- Слишком глубокая рекурсия даёт ошибку «слишком глубокая рекурсия».

## 14в. Имена на кириллице в JavaScript и других языках

- В JavaScript каждое имя получает префикс `$` (`счёт` → `$счёт`), так что оно не совпадёт ни со служебным словом JavaScript, ни с внутренними именами компилятора.
- `ponyatny компилировать файл.pon --ascii` записывает имена только латиницей: каждый не-ASCII символ заменяется на `$` и 6 шестнадцатеричных цифр (`ж` → `$$000436`). Такая запись взаимно однозначна — два разных имени никогда не совпадут.
- `ponyatny перевести файл.pon --в python --латиница` (также javascript, csharp) переводит русские имена транслитерацией: `счёт` → `schyot`, `Щука` → `Shchuka`. Если получилось имя, которое уже занято (другим именем, служебным словом языка или функцией из подготовительного кода переводчика), добавляется `_`, `_2`, `_3` …: `привет` → `privet`, а `privet` → `privet_`. Без `--латиница` русские имена остаются русскими (Python, JavaScript и C# их поддерживают), а совпадения со служебными словами всё равно разводятся через `_`.
- При переводе с Python или JavaScript в «Понятный» имена, которых нет в языке, переводятся безопасно: `$x` → `u24_x`, `π` → `u3c0_`, смешанное `getИмя` → `get_Имя`, служебные слова «Понятного» получают `_`. Имена Python приводятся к NFKC, как это делает сам Python (`ﬁle` и `file` — одно имя).

## 15. Грамматика (EBNF)

```ebnf
программа      = { пустая_строка | команда } ;
команда        = ( объявление | вывод | присваивание | выражение_команда
                 | если | пока | повторить | для | функция | возврат
                 | "стоп" | "дальше" | бросить | попробуй | выбор
                 | класс | структура | подключить ) конец_строки ;

объявление     = ( "пусть" [ "навсегда" ] | "константа" ) имя [ ":" тип ] "=" выражение ;
вывод          = "напиши" [ выражение { "," выражение } ] ;
присваивание   = цель ( "=" | "+=" | "-=" | "*=" | "/=" | "%=" ) выражение ;
цель           = имя | постфикс "[" выражение "]" | постфикс ( "." | "?." ) имя ;
выражение_команда = выражение ;

если           = "если" выражение [ "то" ] КС блок
                 { "иначе" "если" выражение [ "то" ] КС блок }
                 [ "иначе" КС блок ] "конец" ;
пока           = "пока" выражение КС блок "конец" ;
повторить      = "повторить" выражение "раз" КС блок "конец" ;
для            = "для" ( "каждого" имя [ "," имя ] "из" выражение
                       | имя "от" выражение "до" выражение [ "шаг" выражение ] )
                 КС блок "конец" ;
функция        = "функция" имя параметры [ ( "->" | ":" ) тип ] КС блок "конец" ;
параметры      = "(" [ параметр { "," параметр } ] ")" ;
параметр       = имя [ ":" тип ] [ "=" выражение ] ;
возврат        = "верни" [ выражение ] ;
бросить        = "брось" выражение ;
попробуй       = "попробуй" КС блок
                 [ "если" "ошибка" [ "как" имя ] [ "то" ] КС блок ]
                 [ "наконец" КС блок ] "конец" ;
выбор          = "выбор" выражение КС { вариант } [ "иначе" КС блок ] "конец" ;
вариант        = ( "вариант" выражение { "," выражение } [ "если" выражение ]
                 | "когда" имя [ "если" выражение ] ) [ "то" ] КС блок ;
класс          = "класс" имя [ "наследует" имя ] КС
                 { ( "функция" имя параметры [ "->" тип ] КС блок "конец"
                   | "пусть" имя [ ":" тип ] [ "=" выражение ] ) КС } "конец" ;
структура      = "структура" имя параметры ;
подключить     = "подключи" строка ;
блок           = { пустая_строка | команда } ;
КС             = конец_строки ;

выражение      = или { ( "затем" | "|>" ) звено_конвейера } ;
звено_конвейера = имя [ аргументы ] | постфикс ;
или            = и { "или" и } ;
и              = не { "и" не } ;
не             = "не" не | сравнение ;
сравнение      = сумма [ ( "==" | "!=" | "<" | ">" | "<=" | ">=" | "в" | "не" "в" ) сумма ] ;   (* цепочка a < b < c запрещена *)
сумма          = произведение { ( "+" | "-" ) произведение } ;
произведение   = унарное { ( "*" | "/" | "%" ) унарное } ;
унарное        = ( "-" | "+" ) унарное | степень ;
степень        = постфикс [ "^" унарное ] ;
постфикс       = первичное { аргументы | ( "[" | "?.[" ) выражение "]"
                            | ( "." | "?." ) имя [ аргументы ] } ;
аргументы      = "(" [ выражение { "," выражение } ] ")" ;
первичное      = число | строка | "истина" | "ложь" | "ничего" | "это" | "себя"
               | "родитель" "." имя аргументы
               | "новый" имя [ аргументы ]
               | имя [ "=>" выражение ]
               | "функция" параметры ( "=>" выражение | КС блок "конец" )
               | "если" выражение "то" выражение "иначе" выражение
               | "(" выражение ")"
               | "[" [ выражение { "," выражение } [ "," ] ] "]"
               | "{" [ пара { "," пара } [ "," ] ] "}" ;
пара           = ( имя | выражение ) ":" выражение ;
тип            = имя | "ничего" ;

строка         = '"' { символ | вставка } '"' | "«" { символ | вставка } "»" ;
вставка        = "{" выражение "}" ;
число          = цифра { цифра | "_" } [ "." цифра { цифра } ] ;
имя            = ( буква | "_" ) { буква | цифра | "_" } ;   (* кроме служебных слов; буква — кириллица или латиница;
                                                       в одной части между "_" — один алфавит; не длиннее 255 *)
комментарий    = ( "#" | "//" ) { любой_символ } конец_строки ;
```

## 16. Пример программы

```
# Оценки учеников
константа ПРОХОДНОЙ = 4
пусть оценки = {"Ваня": 5, "Маша": 3, "Петя": 4}

функция итог(балл: число) -> строка
    выбор балл
        вариант 5
            верни "отлично"
        когда б если б >= ПРОХОДНОЙ то
            верни "хорошо"
        иначе
            верни "надо подтянуть"
    конец
конец

для каждого имя, балл из оценки
    напиши "{имя}: {балл} — {итог(балл)}"
конец

пусть лучшие = оценки.ключи().отфильтруй(у => оценки[у] >= ПРОХОДНОЙ)
напиши "Прошли:", лучшие затем соедини(", ")
```
Вывод:
```
Ваня: 5 — отлично
Маша: 3 — надо подтянуть
Петя: 4 — хорошо
Прошли: Ваня, Петя
```

## 17. Совместимость с версией 1
