# Понятный

Язык программирования на понятном русском. Есть компилятор в JavaScript, сборка программ в `.exe`, песочница в браузере и переводчик с Python, JavaScript и C# и обратно.

- Песочница: https://ponyatny.vercel.app
- Полный синтаксис и грамматика: [docs/СИНТАКСИС.md](docs/СИНТАКСИС.md)
- Скачать компилятор: раздел Releases (`ponyatny.exe` для Windows, `ponyatny-linux` для Linux)

## Компилятор

```
ponyatny запустить программа.pon          выполнить
ponyatny собрать программа.pon            получить программа.exe (на Windows) или исполняемый файл (на Linux)
ponyatny собрать программа.pon -o игра    своё имя файла
ponyatny компилировать программа.pon      получить программа.js для Node.js
ponyatny проверить программа.pon          только найти ошибки
ponyatny перевести программа.pon --в python      также javascript, csharp
ponyatny перевести скрипт.py --в понятный        также .js
ponyatny программа.pon                    коротко = запустить
ponyatny компилировать программа.pon --ascii           имена в JavaScript только латиницей
ponyatny перевести программа.pon --в python --латиница  русские имена — транслитом
```

Переводчик — отдельная команда по желанию: `запустить`, `собрать`, `компилировать` и `проверить` всегда работают настоящим компилятором и переводчик не используют.

## Что нового в 2.4 (универсальный язык и шуточный диалект)

- **Переменные**: `переменная`, `пусть а, б = 1, 2`, обмен `а, б = б, а`, `ленивая`, `глобальная`, тип `целое`.
- **Циклы**: `делай … конец пока условие`; формы слов `повтори 3 раза`, `для каждой … в …`, `для i с 1 по 10 шагом 2`.
- **ООП**: `интерфейс` и `реализует`, `общая` (static) и `скрытая` (private) поля и функции, `свойство`, `абстрактная функция`, `экземпляр(x, Класс)`.
- **Перечисления** `перечисление Цвет … конец`, **множества** `множество([…])`.
- **Ошибки по типам**: встроенный класс `Ошибка`, несколько блоков `если ошибка Тип как е`, `убедись`, `проверь`, `выход(код)`.
- **Вывод в поток ошибок**: `предупреди`, `отладка`.
- **Новые функции**: `нацело`, побитовые `бит_и/бит_или/бит_искл/бит_не/сдвиг_…`, `символ`, `код`, `в_json`/`из_json`, `нумеруй`, `попарно`, файлы и папки, шаблоны строк (`совпадает`, `найди_все`, `заменить_шаблон`), `любой`/`все`/`найди_где` у списков.
- **Синонимы, формы слов и шуточный диалект**: `напечатай`, `выведи`, `ежели`, `покуда`, `паника "…"`, `кричи на систему`, `шепни`, `спасите … на случай беды … в любом случае … аминь`, `ну всё`, `считай до трёх`, `зуб даю` и другие — раздел 17 [описания синтаксиса](docs/СИНТАКСИС.md). Старые программы работают без изменений: новые слова понимаются только в начале команды и не мешают одноимённым переменным.

## Что нового в 2.1 (безопасность и опечатки)

- **Опечатки прощаются**: `пуст x = 1`, `напишы x`, `конц`, `повторить 3 рза` исправляются автоматически с предупреждением, но только там, где это не может изменить смысл программы. Подробно — в разделе 14а [описания синтаксиса](docs/СИНТАКСИС.md).
- **Имена на кириллице**: любая кириллица, контроль смешения русских и латинских букв-двойников, флаг `--ascii` для JavaScript и `--латиница` для перевода без совпадений имён.
- **Защита**: запрет невидимых символов направления текста (Trojan Source, CVE-2021-42574), закрыт доступ к `constructor`/`__proto__` и другим внутренностям JavaScript, ограничение глубины вложенности и длины строк, песочница выполняет код в изолированном `iframe` с политикой CSP, `собрать` не перезапишет исходник или сам компилятор, `chcp` на Windows вызывается по полному пути.
- **Строгие правила**: цепочка сравнений `a < b < c` теперь ошибка; `подключи` подключает только файлы `.pon`; новое экранирование `\u{КОД}`.
- Полный отчёт проверки: [docs/АУДИТ.md](docs/АУДИТ.md).

### Несовместимые изменения 2.1

- `a < b < c` и `a == b == c` — ошибка компиляции (раньше молча считалось как `(a < b) < c`).
- Имена со смешением русских и латинских букв в одной части (`сoк`) и с невидимыми символами — ошибка.
- Символы направления текста запрещены и в строках, и в комментариях (пишите `\u{…}`).
- `x.constructor`, `x.toString`, поля и функции классов с именами `__…`, `constructor` и т. п. — ошибка.
- `подключи "файл"` ищет только `файл.pon` (раньше подключался любой существующий файл).
- `собрать файл` без расширения `.pon` на Linux теперь создаёт `файл.bin` (раньше исходник перезаписывался).
- Тексты подсказок: «Может быть, …?» заменено на «Возможно, вы имели в виду …?».

Как устроен: лексер → парсер → дерево программы → семантическая проверка (имена, константы, `навсегда`, `стоп` вне цикла, число значений у функций, типы) → генерация JavaScript. `собрать` дописывает скомпилированную программу к копии самого компилятора, поэтому получившийся `.exe` запускается без установки чего-либо.

Переводчик помечает неточные места строками `ПРИМЕЧАНИЕ` в коде и списком в конце; ничего не угадывает молча.

## Пример

```
функция факториал(н)
    если н <= 1 то
        верни 1
    конец
    верни н * факториал(н - 1)
конец
пусть имя = спроси("Как тебя зовут?")
напиши "Привет, {имя}! 10! = {факториал(10)}"
```

Ещё примеры — в папке `primery/`.

## Разработка

- `npm test` — тесты (язык, ошибки, переводчик; C# — с `PON_CSHARP=1` и установленным dotnet)
- `npm run build:web` — собрать песочницу в `public/`
- `npm run build:exe` — собрать `dist/ponyatny.exe` и `dist/ponyatny-linux` (Node.js SEA)
