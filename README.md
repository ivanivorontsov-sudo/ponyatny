# Понятный

Язык программирования на понятном русском. Работает прямо в браузере (песочница с кнопкой «Запустить») и в командной строке через Node.js.

## Запуск

- В браузере: открой песочницу https://ponyatny.vercel.app, напиши код, нажми «▶ Запустить» (или Ctrl+Enter).
- В терминале: `node src/cli.js primery/privet.pon`
- Тесты: `npm test`

## Шпаргалка

| Что | Как пишется |
|---|---|
| Комментарий | `# текст` или `// текст` |
| Переменная | `пусть x = 5`, потом `x = x + 1` |
| Вывод | `напиши "Сумма:", x` |
| Ввод | `пусть имя = спроси("Как тебя зовут?")` |
| Число из текста | `число("42")` |
| Условие | `если x > 3 то … иначе если … то … иначе … конец` |
| Цикл «пока» | `пока x < 10 … конец` |
| Повтор | `повторить 3 раз … конец` |
| Перебор | `для каждого ч из [1, 2, 3] … конец`, `для каждого i из от(1, 10) … конец` |
| Выход из цикла | `стоп` |
| Функция | `функция квадрат(x) … верни x * x … конец` |
| Список | `пусть с = [1, 2]`, `с[0]`, `добавь(с, 3)`, `убери(с, 0)`, `длина(с)` |
| Логика | `истина`, `ложь`, `ничего`, `и`, `или`, `не` |
| Сравнение | `==  !=  <  >  <=  >=` |
| Арифметика | `+  -  *  /  %`, скобки |
| Строки | `"текст"` или `«текст»`, склеиваются через `+` |

Встроенные функции: `спроси`, `число`, `строка`, `длина`, `добавь`, `убери`, `от`, `случайное(1, 100)`, `округли`, `корень`, `модуль`, `большими`, `маленькими`, `соедини(список, ", ")`.

Ошибки пишутся по-русски с номером строки, например: «Строка 3: не знаю, что такое «у»».

## Пример

Смотри `primery/privet.pon`: приветствие, счёт до пяти, таблица умножения, функция и список.
